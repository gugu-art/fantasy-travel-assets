# 星海之岸 · 图片分类与前端资源

本次新增上传465张PNG：399张地区物品插画，以及66张去重后的现用前端图片。图片保持原分辨率、原始文件字节和透明通道。旧图片、天气图标和字体沿用已验证的GitHub固定版本。

手机底纸、边框、头像框、页面组件及电脑版/手机版羁绊插图，分别存放于images下的mobile-layers、mobile-fill、mobile-reference、mobile-home、bonds等目录。法杖新版在items，正文地区插图在region-arrival。物品文件名中的VIR、SER等代码对应地区，中文名称和品级见对照表。

前端运行文件与样式另存于[runtime](https://github.com/gugu-art/fantasy-travel-assets/tree/main/handbook/runtime/0.1.0-test.5/)。当前角色卡仍由酒馆同源加载JavaScript，图片与字体使用固定提交的GitHub直链。此目录只提供素材与前端文件，不包含聊天存档、游戏变量、整张角色卡或任何账号凭据。
