切换栏母版存于[控件图片分类](../../images/controls/mobile-crystal-master-v1.png)，本目录按脚本、样式和资源清单保存本次前端版本。其他图片沿用images下的地区、装备、素材、食物、头像和页面组件分类；字体及许可位于fonts。

资源路径、文件大小与SHA256见[resource-manifest.json](resource-manifest.json)。本目录不含角色卡、世界书、聊天存档、游戏变量或账号凭据。
